# Инструменты AI

AI может выполнять действия на твоём компьютере через `[ИМЯ аргументы]`.

## Встроенные инструменты

| Инструмент | Что делает |
|-----------|-----------|
| `[CMD команда]` | Выполнить команду в терминале |
| `[READ путь]` | Прочитать файл |
| `[WRITE путь → содержимое]` | Записать файл |
| `[LS путь]` | Показать содержимое папки |

## Пример

```
Ты: создай файл hello.py и запусти

AI: [WRITE hello.py → print("Привет!")]
    [CMD python hello.py]
    "Готово! Вывод: Привет!"
```

## Инструменты плагинов

Плагины могут добавлять свои:

```python
self.tools['WEATHER'] = self._tool_weather

def _tool_weather(self, args: str):
    return f"🌤 {args}: +18°C"
```
