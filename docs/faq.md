# FAQ

## Что такое OpenSaw?

Локальный AI-ассистент. Работает полностью на твоём компьютере, без интернета.

## Нужен ли интернет?

Только чтобы скачать модель (один раз). Дальше — офлайн.

## Сколько весит модель?

Qwen2.5-0.5B: ~0.6 ГБ, 1.5B: ~1.6 ГБ, 3B: ~3.2 ГБ, 7B: ~7.2 ГБ.

## OpenSaw платный?

Нет. MIT лицензия, бесплатно навсегда.

## Можно ли использовать GPU?

Да. NVIDIA CUDA — собери `llama-cpp-python` с `GGML_CUDA=ON`.

## Плагины безопасны?

AI проверяет код плагина перед активацией. Но плагин — это Python, будь внимателен.

## Как обновить?

```bash
cd opensaw && git pull && source venv/bin/activate && pip install -e .
```

## Как удалить?

```bash
rm -rf opensaw && rm -rf ~/.config/opensaw
```

## OpenSaw говорит по-русски?

Да, Qwen2.5 отлично говорит по-русски.

## Что такое GGUF?

Формат моделей для llama.cpp, оптимизированный для CPU.
